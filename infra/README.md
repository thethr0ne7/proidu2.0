# Infrastructure

Production target: Russian-region cloud services, Docker images, private PostgreSQL network, S3 object storage, RabbitMQ, Valkey, TLS reverse proxy, monitoring and independent encrypted backups.

Timeweb Cloud is the primary candidate for the first deployment. Yandex Cloud is the managed scale-up alternative. No infrastructure is provisioned by this blueprint branch. See docs/proidu-4.0/04_INFRASTRUCTURE.md.
