# PROIDU Global

International applicant product surface. Shares the canonical institution/program/source catalogue with PROIDU Russia. Owns country qualification rules, foreign admission pathways, applicant cases, document checklists, partner workflows and language-specific UX.

Do not create a second institution catalogue. Do not infer recognition of foreign diplomas without country-specific evidence and manual review where required. See docs/proidu-4.0/07_INTERNATIONAL_BRANCH.md.
